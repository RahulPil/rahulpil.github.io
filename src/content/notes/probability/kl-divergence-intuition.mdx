The definition $D_{\mathrm{KL}}(p \,\|\, q) = \sum_x p(x) \log \frac{p(x)}{q(x)}$
is correct but rarely the thing that helps me think. Three readings I keep
reaching for instead:

**As a coding penalty.** It's the expected number of extra nats you pay if you
encode samples from $p$ using a code optimized for $q$. The asymmetry stops
feeling weird once you remember the code is built for the wrong distribution,
not the wrong samples.

**As a likelihood ratio in expectation.** $D_{\mathrm{KL}}(p \,\|\, q) = \mathbb{E}_p[\log p - \log q]$
is the average log-likelihood gap between the true model and the candidate, evaluated under
the true data — which is why minimizing KL to data is equivalent to maximum
likelihood, up to a constant.

**As a local quadratic.** Near $p = q$, the KL is approximately $\tfrac{1}{2}$
times a Mahalanobis distance under the Fisher information metric. That's the
fact that makes natural gradients natural, and it's the bridge between the
information-geometric and optimization views of the same object.
